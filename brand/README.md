# llm-gateway brand kit

Source assets for the llm-gateway identity. The formal product name remains
`llm-gateway`; `llmgw` is the compact visual wordmark.

## Contents

- `BRAND.md`: identity, construction, color, accessibility, voice, and usage.
- `tokens.json` and `tokens.css`: portable brand tokens.
- `logos/`: light, inverse, and monochrome logo variants.
- `icons/`: favicon and application-icon variants.
- `og/og-default.svg`: default 1200 by 630 social image.
- `preview.html`: local, dependency-free asset preview.
- `provenance.json` and `LICENSES.md`: origin and licensing notes.

Open `preview.html` directly in a browser. It loads only files in this directory:
there are no external fonts, scripts, images, or CDN dependencies.

The public website consumes purpose-sized copies in `website/`. Update those
copies when an approved source asset changes.
