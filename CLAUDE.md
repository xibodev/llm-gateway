# Working in this repository

See [AGENTS.md](AGENTS.md). It applies to every agent and every contributor.

The short version:

- **This repository is public.** Check file contents, commit messages, AND author identity before every commit.
- **Never commit configuration** — only `*.example` files, with placeholders only.
- **Reference real credentials by path**; never read, paste, or fixture them.
- **Run the gates before pushing**, including `npm run check:dist`.
