Runtime state

Configuration is explicit and layered.

Built-in defaults, one private YAML file, and process environment overrides define the single-node gateway.

ConfigurationPrecedenceProvidersEndpointsPolicyEnvironmentState

Never commit real runtime configuration or credentials. Only placeholder examples belong in the repository.

Precedence

  1. Built-in defaults.
  2. LLMGW_CONFIG, or <state>/config.yaml when unset.
  3. LLMGW_* environment overrides.

LLMGW_CONFIG_SEED copies once when the writable config is missing. Local Compose uses it for the read-only repository seed.

Provider instances

config.yaml
providers:
  local-chat:
    type: ollama
    base_url: http://127.0.0.1:11434
  hosted-chat:
    type: openai_compatible
    registry_id: openrouter
    base_url: https://openrouter.ai/api/v1
    api_key: ${ENV:OPENROUTER_API_KEY}
    timeout: 120

Other fields include region, project, location, default voice, disabled status, and experimental API adaptation. See provider integrations.

Endpoints

config.yaml
endpoints:
  coding:
    failover:
      - { provider: hosted-chat, model: <model-a> }
      - { provider: local-chat, model: <model-b> }

categories remains a deprecated fallback only when endpoints is absent.

Provider resilience policy

Released loader limitationThe released loader does not apply YAML policies, even when an administration save serializes retry or circuit fields. Do not depend on these overrides surviving restart.

Endpoint failover is separately configured under endpoints. Circuit state is process-local. Use the supported fields in the example configuration and read the routing boundary.

State layout

gateway.db is authoritative for IAM, keys, encrypted connections, usage, quotas, audit, alerts, and outbox. Other files include catalog.json, telemetry.db, optional usage.db, plaintext compatibility secrets.json, OAuth cache, logs, and backups.

Private stateReal config.yaml, secrets.json, databases, caches, logs, and archives must never be committed.
