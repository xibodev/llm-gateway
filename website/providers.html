Credential resolution

Generic API-key providers resolve the human's private default connection, then a system connection, then the legacy config/secret seed. Generic system fallback is not project-binding-gated today.

Copilot is stricter: humans use their own OAuth; services require an exact active project/provider/service binding to a gateway-owned credential. Codex OAuth remains human-private.

At-rest qualificationHuman connections are encrypted. System provider keys can also remain in plaintext secrets.json for compatibility, so protect all state and backups.

Three Google paths

Google Gemini uses the OpenAI-compatible endpoint. Google AI Studio uses native Gemini and supports image/video. Vertex AI uses native Gemini/Vertex with project and location scope. IDs and availability differ by API and location.

Local detection

The console can probe common addresses for Ollama, LocalAI, LM Studio, vLLM, Jan, text-generation web UI, and llama.cpp, including host.docker.internal. Detection reports candidates; the operator adds them. Silent auto-add is opt-in.

Lifecycle evidence

  • Check reachability: catalog endpoint answered.
  • Sync catalog: model/capability rows persisted.
  • Test completion: a real inference request succeeded.
  • Clear cache and retry: local cache reset only; cannot repair credentials or entitlement.

Provider risk boundaries

Respect subscription terms. No Claude personal OAuth, browser-cookie extraction, stealth session reuse, or official-client impersonation is implemented. Edge TTS and Azure discovery can change independently of this project.
