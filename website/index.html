One gateway for all your coding-CLI models

A standalone, multi-provider LLM proxy for Claude Code, Copilot CLI and Codex. Juggle subscription limits, survive outages, and reach any provider's models through one endpoint.

Get started See features 
# point your CLI at the gateway, then address any model as an endpoint…
curl http://127.0.0.1:8787/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"smart","messages":[{"role":"user","content":"hi"}]}'

# "smart" is your failover chain: try the premium model, fall back on 429/5xx
smart: copilot/gpt-5.5  →  copilot/claude-sonnet-4.5  →  localai/gemma-3-4b-it

Built to juggle providers

Address a real model as provider/model, or define endpoints — named, ordered failover chains that cascade across your providers on throttle, error, or timeout.

🔄

Endpoints & failover

One model name, an ordered chain of real targets. Fails over before the first streamed byte — invisible to the client.

🧭

API adaptation

Opt-in: reach Responses-only models (like gpt-5.5) over the standard chat API — the gateway translates, deterministically, from each model's published capabilities.

🏠

Local providers

Auto-discover Ollama, LocalAI, LM Studio & more on your machine — surfaced, never hardwired. A free local model makes a great last link in a chain.

🔑

Project keys & governance

Mint per-project keys with expiry, model/provider allowlists, rate limits and daily budgets — disable any key instantly.

🎤

Multimodal

Audio transcription & speech (via LocalAI whisper/piper) and capability-aware vision routing — multimodal requests land on vision-capable models.

⚡

Tiny footprint

A ~16 MB static Go binary / ~2 MB distroless image, ~15 MiB idle RAM. A Python build is available too.

Quickstart

Run it, connect your providers in the panel, then point a CLI at it.

1

Run the gateway

# Docker (tiny distroless image)
docker run -p 8787:8787 -v llmgw:/state \
  llm-gateway-go
2

Connect providers

# open the panel, add providers,
# sign into Copilot, build endpoints
http://127.0.0.1:8787/admin
3

Address a model

# an endpoint name…
"model": "smart"
# …or an exact provider/model
"model": "copilot/gpt-4o-mini"

Connect a coding CLI

It speaks both the OpenAI and Anthropic wire formats — most tools just need a base URL and a key.

■

Claude Code

ANTHROPIC_BASE_URL=http://127.0.0.1:8787
ANTHROPIC_AUTH_TOKEN=<your key>
■

Codex

base_url=http://127.0.0.1:8787/v1
■

Copilot CLI (BYOK)

COPILOT_PROVIDER_BASE_URL=http://127.0.0.1:8787/v1
COPILOT_PROVIDER_API_KEY=<your key>
💡Pick a provider/model or an endpoint name from GET /v1/models. Everything — providers, endpoints, keys, Copilot login, usage & savings — is managed from /admin.
